Política de Privacidade

O Oss Timer guarda apenas no aparelho os ajustes, os treinos e o histórico de até 200 treinos concluídos, usando as chaves locais oss-timer.treinos.v1, oss-timer.ajustes.v2, oss-timer.ajustes.v1 (legada), oss-timer.historico.v1 e oss-timer.rondas.v1.

A foto exibida na tela Sobre faz parte deste aplicativo e não é enviada para lugar nenhum.

Arquivos e recursos podem ficar armazenados pelo cache do navegador para funcionamento offline. Não há conta, analytics nem envio de dados a servidor. Para apagar os dados, limpe os dados do site no navegador ou remova o aplicativo.
